# Keywords for campaign import (English)

Use these CSV files with **Импорт CSV** on the Keywords page.

| File | Campaign type |
|------|----------------|
| `keywords_click_box.csv` | Click Box |
| `keywords_clicker.csv` | Clicker / Casual clicker |
| `keywords_survey.csv` | Survey |
| `keywords_social_video.csv` | Social / Video survey |
| `keywords_survey_mix.csv` | Survey Mix |
| `keywords_casual.csv` | Casual games |

One keyword per line. Select campaign → set Volume if needed → Импорт CSV → choose file.
