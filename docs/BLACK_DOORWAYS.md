# Чёрные дорвеи: как выжать максимум и прожить дольше

Режим **«чёрная кампания»** (`is_black`) — агрессивный охват длиннохвоста и вариаций. Риск выше, поэтому в коде и в операционке заложены меры, чтобы не палиться в первый же день.

---

## Что уже делает платформа

### Клоака
- **Людям** отдаётся чистая конверсионная страница (без блока «похожие темы»).
- **Ботам** — та же страница + блок `seo_tail` (15–25 семантических вариаций/длиннохвост) внизу, без exit-intent и трекинга.
- См. `docs/nginx-cloaking.conf`: по User-Agent отдаётся `index.seo.html` или `index.html`.

### Бот-версия (SEO) — меньше следов
- Только схема **WebPage** (без Article) — единый тип разметки.
- **Нет блока внутренних ссылок** на другие дорвеи домена — меньше footprint «все страницы ссылаются друг на друга».
- Нет скриптов аналитики, пикселей, exit-intent, квиза в бот-версии.

### Контент
- Промпт для чёрных: естественность, разная длина предложений/абзацев, LSI/синонимы, без шаблонных фраз.
- **Temperature 0.75** при генерации (вместо 0.6) — больше вариативности текстов.
- `seo_tail` — одна естественная строка «похожие темы: …», не переспам ключа.

### Деплой
- При **batch deploy** для кампании с `is_black` автоматически включается **удлинённый stagger**: 60–300 сек между страницами (вместо 30–180). Меньше «всплеска» по времени.

### Анти-детект (общий)
- Разные layout'ы, порядок блоков, варианты trust/CTA по seed от URL.
- Stagger между деплоями, проверки контента (длина, ключ в title/content, чёрный список шаблонных фраз).

## Рекомендации по эксплуатации

1. **Отдельный домен под чёрную кампанию**  
   Не смешивать с белыми дорвеями на одном домене. Один домен — одна ниша и один «тип» контента.

2. **Не выкатывать всё скопом**  
   Лучше 10–30 страниц в день с растяжкой по времени (используйте batch deploy со stagger), чем 500 за вечер. Платформа уже ставит для чёрных 60–300 сек между деплоями в батче.

3. **Включить клоаку на сервере**  
   Nginx по User-Agent должен отдавать боту `index.seo.html`, человеку — `index.html`. Иначе скрытый блок увидят и пользователи, и детекты.

4. **Не лить массовый линкбилдинг на чёрные домены**  
   Резкий прирост ссылок на «свежий» домен с агрессивным контентом — сильный сигнал.

5. **Разносить по хостам/ASN**  
   Не держать десятки чёрных доменов на одном IP/провайдере. Разные серверы/регистраторы снижают корреляцию.

6. **Следить за качеством контента**  
   Перед деплоем смотреть отчёт валидации (шаблонные фразы, длина). При необходимости перегенерировать с тем же ключом.

7. **Sitemap и индексация**  
   Не обязательно слать в GSC все URL сразу. Можно добавить в sitemap первую партию страниц и подождать естественного обхода.
