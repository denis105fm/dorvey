# Настройки — подробное руководство

Все настройки **привязаны к текущему пользователю**. У каждого свой набор настроек.

> **Первый запуск?** См. [FIRST_RUN.md](FIRST_RUN.md) — что нужно для первого полного цикла (генерация → деплой), а что можно отложить.

---

## 1. White-label (Брендинг)

### Что это и зачем

Если вы используете Dorvey для своих клиентов или под своей компанией — можно сменить внешний вид админки. Вместо «Dorvey» будет ваше название, свой цвет, логотип.

### Поля

| Поле | Что вводить | Пример |
|------|-------------|--------|
| **Название бренда** | Текст, который будет в левом сайдбаре вместо «Dorvey» | My Agency |
| **Цвет** | HEX-код цвета для кнопок и акцентов | #10b981 |
| **URL логотипа** | Прямая ссылка на картинку логотипа (PNG, SVG). Показывается вместо названия | https://yoursite.com/logo.png |
| **URL favicon** | Прямая ссылка на иконку для вкладки браузера | https://yoursite.com/favicon.ico |

### Как настроить

1. Заполните нужные поля.
2. Нажмите **«Сохранить брендинг»**.
3. Обновите страницу — изменения применятся к сайдбару.

### Кого это затрагивает

Визуальные настройки видны всем, кто открывает админку (фронт общий). Если нужен разный брендинг для разных пользователей — это отдельная доработка.

## 2. OpenAI (AI)

### Что это и зачем

Dorvey может генерировать контент для дорвеев через GPT. Нужен API-ключ OpenAI.

**Без ключа:** генерация через AI недоступна, будет простой шаблонный текст.

**С ключом:** можно генерировать текст, заголовки, описания, использовать AI Optimizer для рекомендаций.

### Где именно используется

- Раздел **«Дорвеи»** → кнопка **«Сгенерировать»** — создание контента для дорвея.
- **AI Optimizer** — подсказки по улучшению контента и применению изменений.

### Как получить API-ключ

1. Зайдите на [platform.openai.com](https://platform.openai.com).
2. Войдите или зарегистрируйтесь.
3. **API Keys** → **Create new secret key**.
4. Скопируйте ключ (начинается с `sk-...`).

### Как настроить в Dorvey

1. Вставьте ключ в поле **«OpenAI API ключ»**.
2. Нажмите **«Сохранить интеграции»** (внизу страницы).
3. Ключ сохраняется у вас в настройках (по пользователю).

### Альтернатива: глобальный ключ

Можно задать `OPENAI_API_KEY=sk-...` в `.env` на сервере. Тогда ключ общий для всех пользователей. Если ключ задан и в `.env`, и в настройках — используется персональный из настроек.

## 3. Webhooks

### Что это и зачем

Webhooks — это URL вашего сервера, на которые Dorvey отправляет POST-запрос с данными при определённых событиях. Нужно, чтобы вы могли:

- сохранять события в своей БД;
- запускать свои скрипты;
- интегрировать Dorvey с внешними системами.

### События

| Событие | Когда срабатывает |
|---------|-------------------|
| `doorway.deployed` | Дорвей успешно задеплоен |
| `doorway.conversion` | Зафиксирована конверсия (клик по офферу, postback) |
| `doorway.rollback` | Выполнен откат контента дорвея |

### Формат запроса

Dorvey отправляет `POST` с телом JSON, например:

```json
{
  "event": "doorway.deployed",
  "doorway_id": 123,
  "domain": "example.com",
  "timestamp": "2025-02-14T12:00:00Z"
}
```

### Как настроить

1. Подготовьте endpoint на своём сервере (например, `https://your-server.com/webhook`), который принимает POST и возвращает 200.
2. В Dorvey введите этот URL в поле **«Webhook URL»**.
3. Нажмите **«Добавить»**.
4. URL появится в списке. Можно добавить несколько webhooks.

### Удаление

Нажмите **«Удалить»** рядом с нужным URL.

## 4. Уведомления (Telegram, Slack, Email)

### Что это и зачем

Dorvey может отправлять уведомления о важных событиях: деплой, конверсия, откат. Можно выбрать один или несколько каналов.

---

### Telegram

**Что нужно:** Bot Token и Chat ID.

**Как получить Bot Token:**
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot`, придумайте имя.
3. BotFather даст токен вида `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`.

**Как получить Chat ID:**
1. Напишите своему боту любое сообщение.
2. Откройте в браузере: `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`.
3. В ответе найдите `"chat":{"id": 123456789}` — это Chat ID.

**Как настроить:**
1. Вставьте Bot Token и Chat ID в соответствующие поля.
2. Нажмите **«Сохранить интеграции»**.

---

### Slack

**Что нужно:** Incoming Webhook URL.

**Как получить:**
1. В Slack: **Apps** → **Incoming Webhooks** → **Add to Slack**.
2. Выберите канал для уведомлений.
3. Скопируйте URL вида `https://hooks.slack.com/services/T00.../B00.../xxx`.

**Как настроить:**
1. Вставьте URL в поле **«Slack Incoming Webhook URL»**.
2. Нажмите **«Сохранить интеграции»**.

---

### Email

**Что нужно:**
1. Включить чекбокс **«Email уведомления»**.
2. Настроить SMTP в `.env` на сервере:

```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your@email.com
SMTP_PASSWORD=your-app-password
SMTP_FROM=your@email.com
```

Уведомления будут уходить на email, привязанный к аккаунту Dorvey.

## 5. Google Search Console (GSC)

### Что это и зачем

GSC позволяет отправлять sitemap и URL в Google, чтобы страницы быстрее индексировались. Dorvey может делать это автоматически, если есть OAuth-доступ.

### Что нужно

- **Client ID** и **Client Secret** — из Google Cloud Console.
- **Refresh Token** — получается один раз после OAuth flow.

### Как получить Client ID и Secret

1. [Google Cloud Console](https://console.cloud.google.com) → выберите или создайте проект.
2. **APIs & Services** → **Credentials** → **Create Credentials** → **OAuth client ID**.
3. Тип: **Web application**.
4. Добавьте в **Authorized redirect URIs** адрес вида: `https://ваш-dorvey.ru/api/indexing/gsc/callback` (или ваш APP_URL + путь).
5. Сохраните Client ID и Client Secret.

### Как получить Refresh Token

Обычно через специальный flow в Dorvey (если реализован) или вручную:

1. Формируете OAuth URL для GSC.
2. Пользователь авторизуется и даёт доступ.
3. По callback получаете Refresh Token.
4. Вставляете его в настройки.

Если в Dorvey нет встроенного OAuth flow для GSC — Refresh Token придётся получить отдельным скриптом и вставить вручную.

### Где используется

Раздел **Indexing** — отправка sitemap и URL в Google Search Console.

## 6. Bing Webmaster

### Что это и зачем

Аналог GSC, но для Bing. Позволяет отправлять sitemap в Bing Webmaster Tools.

### Как получить API Key

1. [Bing Webmaster Tools](https://www.bing.com/webmasters).
2. Добавьте сайт.
3. **Settings** → **API Access** → создайте API key.
4. Скопируйте ключ.

### Как настроить

1. Вставьте API Key в поле **«Bing API Key»**.
2. Нажмите **«Сохранить интеграции»**.

## 7. SSL (Let's Encrypt)

### Что это и зачем

При деплое дорвея на свой сервер можно автоматически получить бесплатный SSL-сертификат (HTTPS) через Let's Encrypt.

### Как работает

При включённом флаге и деплое через **SSH** Dorvey на целевом сервере вызывает certbot, который выпускает сертификат для домена дорвея.

### Важно

- Работает только при деплое через **SSH** (не FTP).
- На сервере должны быть открыты порты **80** и **443**.
- Certbot должен быть установлен на целевом сервере.
- Домен должен указывать на этот сервер (DNS уже настроен).

### Как настроить

1. Включите чекбокс **«Автоматически выпускать SSL (Let's Encrypt) при деплое»**.
2. Нажмите **«Сохранить интеграции»**.

После этого при каждом новом деплое через SSH будет пробоваться выпуск SSL.

## 8. Voluum / Binom

### Что это и зачем

Voluum и Binom — трекеры для арбитража трафика. Dorvey может передавать данные о конверсиях в эти системы, чтобы вы видели статистику в одном месте.

### Что нужно

Для каждого трекера:
- **API Key** — ключ доступа к API.
- **API URL** — базовый URL API (например, `https://api.voluum.com`).

### Где взять

- **Voluum:** личный кабинет → API / Integrations.
- **Binom:** настройки → API.

### Как настроить

1. Заполните Voluum API Key и Voluum API URL (если используете Voluum).
2. Заполните Binom API Key и Binom API URL (если используете Binom).
3. Нажмите **«Сохранить интеграции»**.

### Что влияет

При конверсиях Dorvey будет отправлять данные в настроенные трекеры. Это нужно, если вы ведёте кампании через Voluum/Binom и хотите видеть конверсии там.

## 9. Heatmaps (Hotjar, Clarity)

### Что это и зачем

- **Hotjar** — карты кликов, записи сессий, опросы.
- **Microsoft Clarity** — бесплатные карты кликов и запись сессий.

Если указать их ID в настройках, Dorvey автоматически добавит их скрипты во все дорвеи. Не нужно вручную править шаблоны.

### Где взять ID

- **Hotjar:** сайт hotjar.com → Add new site → Site ID.
- **Clarity:** clarity.microsoft.com → New project → Project ID.

### Как настроить

1. Вставьте **Hotjar Site ID** (число).
2. Вставьте **Microsoft Clarity Project ID** (строка).
3. Нажмите **«Сохранить интеграции»**.

### Что влияет

Скрипты будут подключаться ко всем дорвеям. Данные будут идти в ваши проекты Hotjar и Clarity.

## 10. Конверсия (Exit-intent, Trust-элементы)

### Что это и зачем

Два приёма для повышения конверсии на дорвеях:

---

### Exit-intent

Когда пользователь собирается закрыть вкладку (курсор уходит к кнопке закрытия), показывается попап вроде «Подождите! Есть специальное предложение». Это даёт дополнительный шанс удержать клиента.

### Trust-элементы

Под контентом дорвея появляются иконки/блоки: «Безопасно», «Проверено», «Быстро» и т.п. Они повышают доверие и могут увеличить конверсию.

### Как настроить

1. Включите нужные чекбоксы:
   - **Exit-intent: показывать попап при уходе курсора**
   - **Trust-элементы: иконки надёжности**
2. Нажмите **«Сохранить интеграции»**.

### Что влияет

Применяется ко **всем** дорвеям текущего пользователя. Конкретный текст и дизайн зависят от шаблона.

## 11. Billing (Тарифы)

### Что это

Информационный блок: ваш тариф, сколько из лимитов вы использовали.

### Что отображается

- План: free / pro / enterprise.
- Использование: doorways, campaigns, domains (текущее значение / лимит).
- Цены тарифов.

### Можно ли менять здесь

Нет. План и лимиты задаются через админку или БД. Здесь только просмотр.

## 12. 2FA (двухфакторная аутентификация)

### Что это и зачем

При входе кроме пароля нужен одноразовый код из приложения (Google Authenticator, Authy и т.п.). Защищает аккаунт при утечке пароля.

### Как включить

1. Нажмите **«Включить 2FA»**.
2. Откроется QR-код — отсканируйте его в Google Authenticator или Authy.
3. Введите 6-значный код из приложения.
4. Нажмите **«Подтвердить»**.

После этого при каждом входе потребуется код из приложения.

### Как отключить

1. Введите текущий код из приложения.
2. Нажмите **«Отключить 2FA»**.

## 13. Cron

### Что это и зачем

Cron — это автоматические задачи, которые нужно запускать **раз в день** (или по расписанию). Они:

- откатывают контент при падении CR;
- ставят на паузу убыточные дорвеи;
- меняют офферы при падении CR;
- ставят на паузу кампании при проблемах партнёрки.

В интерфейсе показаны только **команды** — их нужно вызывать с вашего сервера или через Celery Beat.

### Задачи

| Что делает | Endpoint | Параметры |
|------------|----------|-----------|
| Откат контента при падении CR | `POST /api/cron/auto-rollback` | `threshold_percent=15` — падение CR на 15% и больше; `min_days=7` — минимум 7 дней данных |
| Пауза убыточных дорвеев | `POST /api/cron/auto-pause-unprofitable` | `min_days=14` — убыток минимум 14 дней |
| Смена офферов при падении CR | `POST /api/cron/auto-switch-offers` | `threshold_percent=15`, `min_days=7` — для кампаний с 2+ офферами |
| Пауза при проблемах партнёрки | `POST /api/cron/pause-on-affiliate-issues` | `min_days=7` — падение конверсий 7+ дней |

### Как вызывать

**Вариант 1 — один раз все задачи:**
```bash
curl -X POST "https://ваш-dorvey.ru/api/cron/run-all"
```

**Вариант 2 — системный cron (Linux):**
```cron
0 3 * * * curl -X POST "https://ваш-dorvey.ru/api/cron/run-all"
```
(запуск каждый день в 3:00)

**Вариант 3 — Celery Beat** (если настроен) — задачи уже запланированы.

### Важно

- Endpoint должен быть доступен (не заблокирован файрволом).
- Для доступа может требоваться авторизация — проверьте, как это настроено в вашем проекте.

## Сводка: что сохранять где

| Блок | Кнопка сохранения |
|------|-------------------|
| White-label | **Сохранить брендинг** |
| OpenAI, GSC, Bing, SSL, Voluum, Binom, Heatmaps, Конверсия, Уведомления | **Сохранить интеграции** (одна кнопка внизу) |

## Где хранятся настройки

- **White-label, интеграции, webhooks** — таблица `settings` в БД (по `user_id`).
- **2FA** — поле `two_fa_secret` в таблице `users`.
