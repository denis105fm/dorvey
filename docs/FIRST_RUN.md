# Первый полный цикл: генерация → деплой

Нет, **настраивать всё в начале не обязательно**. Ниже — минимальный набор, чтобы пройти первый цикл от генерации до выкладки дорвея в сеть.

---

## Что нужно обязательно

### 1. Кампания

**Кампании** → «Добавить кампанию»:
- **Название** — любое (например, «Тест»)
- **Affiliate URL** — ссылка на оффер/лендинг (куда ведёт кнопка на дорвее). Можно временно `https://example.com` для теста
- Остальное — по умолчанию

### 2. Сервер

**Серверы** → «Добавить сервер»:
- **Название** — например, «Prod»
- **Хост** — IP или домен сервера, куда деплоите
- **Порт** — 22 (SSH)
- **Пользователь** — SSH-пользователь
- **Путь** — куда класть файлы, например `/var/www/html` или `/home/user/public_html`
- **Тип аутентификации** — SSH ключ или пароль
- **Авто SSL** — можно выключить на первое время

### 3. Домен

**Домены** → «Добавить домен»:
- **Домен** — например `test.example.com` (должен быть привязан к серверу)
- **Сервер** — выберите созданный сервер
- **Кампания** — выберите созданную кампанию (опционально, но удобно)

Важно: DNS домена должен указывать на IP этого сервера.

---

## Что можно не трогать в начале

| Настройка | Когда понадобится |
|-----------|-------------------|
| OpenAI | Хотите AI-генерацию контента — добавьте ключ. Без него будет простой шаблонный текст |
| GSC, Bing | Когда будете индексировать sitemap |
| Voluum, Binom | Когда нужно слать конверсии в трекер |
| Webhooks, уведомления | Когда нужны оповещения о деплое/конверсиях |
| SSL | Когда нужен HTTPS (можно включить позже) |
| Heatmaps, Exit-intent, Trust | Когда нужно аналитика и усиление конверсии |
| 2FA | Когда нужна доп. защита аккаунта |
| Cron | Когда нужна автооптимизация |
| White-label | Когда нужен свой брендинг |

---

## Порядок действий (первый цикл)

### Шаг 1. Создать кампанию, сервер, домен

Как описано выше.

### Шаг 2. (Опционально) OpenAI

**Настройки** → OpenAI → ввести ключ → «Сохранить интеграции».  
Без ключа генерация всё равно возможна, но контент будет базовым.

### Шаг 3. Генерация дорвея

**Дорвеи** → «Сгенерировать»:
- **Кампания** — выберите вашу
- **Домен** — выберите ваш
- **Ключевое слово** — например `кредит наличными`
- **Путь** — `/` или `/kredit` и т.п.

Нажать «Сгенерировать». Появится дорвей в списке.

### Шаг 4. Деплой

В списке дорвеев нажать **«Деплой»** у нужного дорвея. Dorvey зальёт HTML на сервер по SSH.

### Шаг 5. Проверка

Открыть в браузере `http://ваш-домен/путь` — страница должна открываться.

## Офферы (Offers)

Офферы — это отдельные ссылки для разных гео/устройств. Для первого теста достаточно **affiliate_url** в кампании. Офферы можно добавить позже в **Офферы** (привязаны к кампании).

---

## Шаблоны

По умолчанию подставляются seed-шаблоны (миграции). Создавать свои можно позже в **Шаблоны**.

---

## Итого

**Минимум для первого полного цикла:**
1. Кампания (с affiliate_url)
2. Сервер (SSH)
3. Домен (привязан к серверу)
4. Генерация (keyword + path)
5. Деплой

**Из настроек в начале** имеет смысл добавить только **OpenAI**, если нужна AI-генерация. Остальное — по мере необходимости.
