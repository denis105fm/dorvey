# Стратегия: прибыль на 2–3 день и максимум выжима из системы

Цель: система, которой нет ни у кого — выжимает 100% прибыли, прибыль уже на 2–3 день после генерации дорвея.

---

## Уже реализовано

- **Выбор оффера по ROI** — клики и конверсии по офферам, автоматический выбор лучшего по revenue/clicks (минус 5+ кликов). Новые дорвеи и редирект по CTA сразу ведут на самый прибыльный оффер.
- **Ранний стоп (2–3 дня)** — крон `early_pause_no_conversions`: если дорвей задеплоен недавно (настраиваемо, по умолчанию 2 дня), есть трафик (≥30 кликов), но 0 конверсий — ставим на паузу и шлём webhook. Не жжём бюджет на мёртвых дорвеях.
- **API «Ранние дорвеи»** — `GET /api/analytics/early-doorways?days=3&min_clicks=20` — список дорвеев за последние N дней с трафиком и 0 конверсий. Можно вывести в дашборде и быстро менять оффер или паузить.
- **Автопауза убыточных** — после 14 дней без выручки при ≥20 кликах.
- **Пауза при проблемах партнёрки** — падение конверсий по кампании.
- **Автоприменение рекомендаций** — AI рекомендации по CR/CTR и авто-применение по правилам кампании.
- **Рекомендации по странам** — какие гео пробовать по кликам и офферам.
- **Метрики по дорвеям** — profit_status, health_score, profit_probability, бенчмарк по кампании.
- **Биллинг-лимиты** — уведомления при приближении к лимиту и при перерасходе.
- **Winner layout** — для новых дорвеев можно задать выигрышный layout из A/B.

---

## Что можно добавить (идеи)

### Быстро к прибыли (2–3 день)

1. **Дашборд «Первые 48 часов»** — виджет на главной/кампании: список из `early-doorways` + кнопки «Сменить оффер» / «Пауза». Один клик — действие без перехода в детали.
2. **Правило «Ранний стоп» в UI** — в Правилах кампании: вкл/выкл early_pause, min_days (1–7), min_clicks (10–100). Сейчас логика в кроне с дефолтами; отключение — через `affiliate_rules.early_pause.enabled = false`.
3. **Уведомление в Telegram/Email** — при срабатывании early_pause отправлять короткое сообщение: «Дорвей #123 поставлен на паузу: 45 кликов, 0 конверсий за 2 дня. Смените оффер».

### Максимум прибыли

4. **Источник трафика в sub_id** — передавать utm_source или referrer в sub_id (например `dw_oid_src`), считать метрики и ROI по источнику (Google / соцсети / прямой). Оптимизировать оффер/крео под источник.
5. **Ретаргетинг с лучшим оффером** — при пуше/email напоминании подставлять ссылку с лучшим по ROI оффером для этого гео (уже есть visitor_id и гео в мета).
6. **Клонирование победителей** — «Дорвей #X даёт ROI 25% за 7 дней» → кнопка «Клонировать на другой домен» (копирование контента + layout + правил на новый домен/путь).
7. **Прогноз «выйдет в плюс»** — по текущим CR/CTR и бенчмарку кампании показывать: «При текущем трафике дорвей выйдет в плюс через ~N дней» или «Мало данных, добавьте трафик».
8. **Exit-intent с лучшим оффером** — в попапе при уходе показывать не общий affiliate_url, а лучший оффер по ROI для этого гео/устройства (как в CTA).
9. **Сортировка по «прибыльности»** — в списке дорвеев сортировка по health_score или по revenue за 7 дней, чтобы вверху были кандидаты на масштабирование или на паузу.

### Уникальность системы

10. **Кросс-кампания** — «Офферы, которые конвертят в кампании A, часто конвертят в B»: при добавлении оффера в новую кампанию подсказывать офферы из других кампаний того же пользователя по схожим гео/нише.
11. **Нишевые пресеты** — шаблоны контента/офферов по вертикали (кредиты, страхование, подписки) с дефолтными правилами (early_pause, min_clicks, рекомендуемые гео).
12. **Быстрый убийца** — отдельный крон или правило: при 0 конверсий и >50 кликов за 24 часа сразу ставить на паузу (жёстче, чем «за 2 дня»), с webhook.

---

## Рекомендуемый порядок

- Включить **early_pause** в `run-all` (уже включён) и при необходимости вызвать `POST /api/cron/early-pause-no-conversions` вручную или по расписанию (раз в 6–12 ч в первые дни).
- В интерфейсе: страница/блок **«Ранние дорвеи»** с данными из `GET /api/analytics/early-doorways` и действиями «Пауза» / «Сменить оффер».
- Опционально: настройки **Ранний стоп** в Правилах кампании (enabled, min_days, min_clicks) и уведомления при срабатывании.

После этого система уже даёт прибыль на 2–3 день за счёт раннего стопа и выбора оффера по ROI; остальные пункты усиливают эффект и дифференцируют продукт.
