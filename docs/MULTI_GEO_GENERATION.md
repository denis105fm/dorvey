# Генерация под несколько стран и индексация по гео

## Текущее состояние после правок

- **Язык дорвея** задаётся так:
  - если у дорвея задан `target_geo` (например `DE`, `US`) — язык берётся из пресета страны (`get_language_code(target_geo)` → en, de, pl и т.д.);
  - иначе используется язык кампании `camp.language` (дефолт `"en"`).
- Все блоки интерфейса (FAQ, CTA, попап, «Ещё по теме») берут строки из `get_doorway_ui_strings(camp_lang)` — смеси русского и английского на одной странице больше не должно быть.
- В БД у дорвея есть поле **`target_geo`** (миграция 018). Его можно выставлять при создании/генерации под конкретную страну.

## Цель: «генерить на выбранные страны или все гео офферов»

### Вариант A: несколько дорвеев на один «концепт» (рекомендуется для индексации)

- Одна кампания, один домен.
- Для каждого гео — **отдельный дорвей** с одним и тем же смыслом (один и тот же ключ/тема), но своим языком и своим path:
  - `target_geo = "US"` → язык en, path например `/tycoon-clicker` или `/en/tycoon-clicker`;
  - `target_geo = "DE"` → язык de, path `/de/tycoon-clicker`;
  - `target_geo = "PL"` → язык pl, path `/pl/tycoon-clicker`.
- При деплое каждый такой дорвей даёт один HTML с нужным `lang` и контентом на нужном языке.
- В sitemap попадают все URL; у каждого — свой язык и при желании hreflang между языковыми версиями. Индексация идёт по странам за счёт разных URL и правильного `lang`.

Шаги реализации:

1. **Список гео для выбора**
   - API: по `campaign_id` отдать уникальные `Offer.geo` по активным офферам кампании (уже есть похожее в `/keywords/suggest-by-offers-geo` и т.п.).
   - На фронте: при генерации дорвеев показывать мультиселект «Гео» (по умолчанию — гео кампании или все гео офферов).

2. **Генерация «на выбранные страны»**
   - Вход: кампания, ключи/сиды, список гео `["US", "DE", "PL"]`.
   - Для каждой пары (ключ/сид, гео):
     - язык = `get_language_code(geo)`;
     - path = один на гео, например `/{lang_code}/{slug}` для не-дефолтного гео и `/{slug}` для гео кампании (или везде `/{lang_code}/{slug}`);
     - создать дорвей с `target_geo=geo`, `path=...`, контент генерить с `language=...` (уже есть в generator).
   - В результате: несколько дорвеев на один «концепт», каждый со своим языком и path — готово к индексации по странам.

3. **Индексация по странам**
   - В HTML уже есть `<html lang="...">` и контент на нужном языке.
   - В sitemap включать все дорвеи (в т.ч. с разными `target_geo`).
   - Опционально: для одного и того же «концепта» (одинаковый slug, разные языки) добавить в шапку страницы теги `hreflang` на альтернативные URL (en, de, pl), чтобы поисковики понимали связь между версиями.

### Вариант B: один дорвей, несколько контент-вариантов

- В `content_variants` или отдельном JSONB хранить варианты по языкам: `{"en": {...}, "de": {...}}`.
- При деплое рендерить несколько HTML (по одному на язык) с разными path (`/en/...`, `/de/...`).
- Плюс: один запись дорвея на «концепт». Минус: усложнение деплоя и логики путей; нужна аккуратная схема path и sitemap.

Рекомендация: начать с варианта A (отдельный дорвей на гео + `target_geo`), затем при необходимости добавить hreflang и, если понадобится, вариант B.

## Краткий чеклист для реализации «генерация на выбранные страны»

- [x] API: параметр target_geos / target_geo в generate и generate-batch.
- [x] Генератор: target_geo → язык и контент по стране; path = /{lang}/{slug} при нескольких гео.
- [x] Фронт: выбор гео (мультиселект) при одиночной и пакетной генерации; кнопка «Подставить все гео офферов».
- [x] Sitemap: без изменений — в sitemap.xml попадают все дорвеи домена (status in deployed/indexed/draft), включая с разными target_geo. При деплое каждый дорвей получает свой URL (path), все они автоматически добавляются в sitemap.

После этого индексация по странам обеспечивается за счёт разных URL, правильного `lang` и при необходимости hreflang.
