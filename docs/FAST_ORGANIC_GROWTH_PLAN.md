# План быстрого бесплатного роста в поиске

Цель: максимально ускорить индексацию и выход в топ по низкоконкурентным запросам без платной рекламы. Ниже — обязательные доработки и «лазейки», которыми пока мало кто пользуется.

## Принцип: всё автоматически

Система должна быть **умной**: пользователь деплоит дорвеи и при необходимости жмёт одну кнопку — всё остальное делается само. Никакой ручной возни с sitemap, robots, ключами IndexNow, отправкой URL по одному или правкой мета-тегов. Где возможно — полная автоматизация; единственное исключение — одноразовое добавление свойства в GSC (это делается в интерфейсе Google, API не даёт добавить свойство за пользователя).

---

## Часть 1. Обязательные доработки (дыры в текущей системе)

| № | Задача | Зачем | Автоматизация |
|---|--------|--------|----------------|
| 1 | **Деплой sitemap.xml на сервер** | На домене по `https://domain.com/sitemap.xml` должен быть файл — иначе Google не подхватит. | **Авто:** при каждом деплое дорвея домена перегенерировать sitemap (с lastmod) и выкладывать на сервер в корень. Либо по крону раз в день по всем доменам с дорвеями. |
| 2 | **Деплой robots.txt** | Поисковик должен знать путь к sitemap. | **Авто:** генерировать и выкладывать при первом деплое на домен (или вместе с sitemap). Без ручного шага. |
| 3 | **lastmod в sitemap** | Чаще переобход «свежих» URL. | **Авто:** при генерации sitemap подставлять `lastmod` из `updated_at` дорвея. |
| 4 | **Внутренние ссылки в контенте** | Обход и вес по сайту. | **Авто:** при рендере страницы вызывать логику внутренних ссылок (тот же домен, та же кампания), подставлять 2–3 ссылки в блок «Ещё по теме» в шаблоне. Пользователь ничего не настраивает. |
| 5 | **IndexNow при деплое** | Быстрое уведомление Bing, Yandex и др. | **Авто:** ключ IndexNow хранить в настройках домена/пользователя (генерировать один раз при первом включении или из настроек). Ключ-файл выкладывать на сервер при деплое. При каждом деплое/обновлении страницы — отправлять URL в IndexNow. Без ручных действий после настройки. |
| 6 | **Массовая отправка URL в индекс** | Чтобы не слать по одному. | **Авто:** при пакетном деплое уже шлём каждый URL в GSC/Bing после деплоя. Дополнительно: одна кнопка «Отправить все URL домена» в UI (учёт лимита GSC). Минимум ручного — один клик при необходимости. |
| 7 | **Подсказка про sitemap в GSC** | Добавить sitemap в свойство GSC может только пользователь (в UI Google). | **Полуавто:** после деплоя sitemap показывать в UI подсказку: «Скопируйте в GSC → Sitemaps: https://domain.com/sitemap.xml». Один раз на домен. |

## Часть 2. Лазейки и малоиспользуемые приёмы

| Пункт | Действие | Автоматизация |
|-------|----------|----------------|
| **2.1 IndexNow ключ-файл** | Выкладывать файл верификации на сайт. | **Авто:** при деплое sitemap/robots класть и ключ-файл (имя из настроек или сгенерированное). Ключ сохранять в настройках домена/пользователя. |
| **2.2 datePublished в Article** | Передавать дату в схему. | **Авто:** при рендере подставлять `created_at` или `deployed_at` дорвея в ISO 8601. Без настроек. |
| **2.3 HowTo-схема** | Для «инструктивных» дорвеев. | **Авто:** по ключевому слову/шаблону определять, что страница типа «как …», и подставлять HowTo с 3–5 шагами (из контента или пресет). Опционально включать в настройках кампании/шаблона. |
| **2.4 Топическая глубина** | Блок «Связанные темы» с ссылками. | **Авто:** тот же механизм, что и внутренние ссылки — при рендере брать 2–3 дорвея кампании и выводить блок. Без ручного выбора ссылок. |
| **2.5 FAQ 5–8 пар** | Больше пар для PAA/голосового поиска. | **Авто:** в генераторе контента/FAQ по умолчанию генерировать 5–8 пар; сохранять в cloaking_rules.faq_qa и выводить в шаблоне. |
| **2.6 og:image** | Одна крупная картинка для Discover/соцсетей. | **Авто:** при рендере подставлять URL картинки (дефолт на домен/кампанию или из контента, если есть). Мета-тег в шаблоне. |
| **2.7 Core Web Vitals** | Проверка LCP, FID, CLS. | **Авто:** по крону или по кнопке «Проверить» по выборочным URL вызывать PageSpeed Insights (или аналог) и писать результат в отчёт/подсказки. Пользователь только смотрит. |
| **2.8 Длиннохвостые ключевики** | Помечать/фильтровать низкую конкуренцию. | **Авто:** при наличии данных (GSC, FetchSERP и т.п.) помечать ключи в списке и в рекомендациях предлагать сначала генерировать дорвеи по ним. |
| **2.9 Обратные ссылки через изображения** | Тактика с Unsplash/Pexels. | Только документирование в инструкции; в продукт не встраивать. |
| **2.10 Google Indexing API** | Уже используем. | **Уже авто:** отправка после деплоя; лимит учтён. |

## Часть 3. Порядок внедрения (рекомендуемый)

Всё закладываем **сразу с автоматизацией**:

1. **Фундамент:** sitemap + robots.txt на сервере (деплой при деплое дорвея/домена), lastmod в sitemap.  
2. **Уведомления:** IndexNow — ключ в настройках, ключ-файл и отправка URL при каждом деплое автоматически.  
3. **Контент и схема:** внутренние ссылки и «Связанные темы» при рендере без настроек, datePublished в Article из даты дорвея, при желании HowTo по шаблону.  
4. **UI:** кнопка «Отправить все URL домена» (один клик при необходимости), подсказка про добавление sitemap в GSC (один раз на домен).  
5. **Доп. сигналы:** og:image и 5–8 FAQ по умолчанию в генераторе, топический блок = те же внутренние ссылки, проверка CWV по кнопке/крону, рекомендации по длиннохвостовым ключам при наличии данных.

## Реалистичные ожидания

- **«В топ за неделю»** достижимо в основном по низкоконкурентным длиннохвостовым запросам.  
- Комбинация быстрой индексации (sitemap, robots, GSC, IndexNow), нормального title/meta/контента/FAQ и внутренних ссылок повышает шансы.  
- По высококонкурентным запросам быстрый выход без бюджета маловероятен.

---

## Итог: получится?

**Да.** Умная система = максимум автоматики. Ручное только то, что нельзя сделать за пользователя:

- **Один раз на домен:** добавить в GSC свойство и URL sitemap (это делается в интерфейсе Google; API не позволяет добавить свойство за пользователя). Подсказку с готовой ссылкой показываем в UI.
- **По желанию:** одна кнопка «Отправить все URL домена в индекс», если нужно догнать старые страницы.

Всё остальное — деплой sitemap/robots/IndexNow-файла, отправка в GSC/Bing/IndexNow при деплое, внутренние ссылки, даты в схеме, og:image, FAQ 5–8, блок «Связанные темы» — делается системой без ручных шагов.
