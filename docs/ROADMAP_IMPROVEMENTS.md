# План улучшений системы

## Быстрые усиления

- [x] **Порог «с трафиком» в настройках** — минимальное число кликов за период для учёта в доле прибыльных (Настройки → Аналитика и прибыльность).
- [x] **Уведомления при авто-паузе** — в Webhooks описано событие `doorway.auto_paused`; можно добавить URL и подписаться на него.
- [x] **Фильтр прибыльные/убыточные в списке дорвеев** — фильтр «Прибыльность: все / Прибыльные / Убыточные / Без трафика» на странице Дорвеи.
- [x] **Подсказка «почему пауза»** — при авто-паузе сохраняется причина в `pause_reason`, отображается под статусом в таблице дорвеев.

## Средний приоритет

- [x] **Единый скоринг здоровья дорвея 0–100** — колонка «Здоровье» в списке дорвеев (скоринг + метка Прибыльный/Убыточный/Без трафика).
- [x] **Прогноз вероятности прибыли по дорвею** — в метриках дорвея поле profit_probability (низкая/средняя/высокая), отображается в колонке «Здоровье».
- [x] **Бенчмарки по кампании** — средний CR и RPC по кампании; в таблице дорвеев показ «выше/ниже бенчмарка» (CR ↑/↓, RPC ↑/↓).
- [x] **Рекомендации после паузы** — при открытии «Рекомендации» для дорвея на паузе загружаются рекомендации по данным кампании (лучший вариант A/B); блок «По данным кампании» в модалке.

## Требования к веб-интерфейсу

- Визуально красиво: согласованная типографика, отступы, акцентные цвета.
- Анимации: плавные переходы (transition), появление списков/карточек, микро-анимации кнопок.
- Удобно: понятные подписи, тултипы где нужно, логичная группировка.
- Логично: фильтры рядом с данными, действия в контексте карточки.
