# Шаблоны doorway-страниц

## Откуда берутся шаблоны

1. **При миграциях** — добавляются seed-шаблоны (8 шт.).
2. **Создание своих** — в разделе «Шаблоны» можно добавлять и редактировать шаблоны (API).
3. **Встроенный fallback** — если в БД нет шаблонов, генератор использует DEFAULT_PAGE_TEMPLATE.

## Доступные шаблоны (seed)

| Название | Стиль | Ниша |
|----------|-------|------|
| Страница по умолчанию | Зелёный, базовый | Универсал |

| Финансовый | Georgia, teal | Финансы |
| Здоровье / wellness | Мягкий зелёный, фон #f8fafc | Здоровье |
| E-commerce / товары | Оранжевый, акцентный | Товары |
| Медиа / редакционный | Georgia, чёрный CTA | Блоги, медиа |
| Премиум / тёмный акцент | Тёмно-серый CTA | Премиум |
| Полный (все блоки) | Синий, main, все блоки | Универсал |

Каждый поддерживает: `faq_schema`, `article_schema`, exit-intent, trust-блоки, comparison-table.

## Переменные шаблона (Jinja2)

- `{{ title }}` — заголовок страницы
- `{{ meta_description }}` — meta description
- `{{ main_content }}` — HTML-контент (контент, trust-блоки, CTA)
- `{{ language }}` — язык (ru, en)
- `{{ affiliate_url }}` — партнёрская ссылка
- `{{ canonical_url }}` — канонический URL
- `{{ body_class }}` — CSS-класс body (для вариативности)
- `{{ faq_schema }}`, `{{ article_schema }}` — JSON-LD-схемы
- `{{ exit_intent_enabled }}` — флаг exit-intent модалки

## Типы шаблонов

- `page` — полная страница (используется при генерации doorway)
- `block` — фрагмент (для будущего использования)
- `style` — стили (для будущего использования)

## API

- `GET /api/templates/` — список
- `POST /api/templates/` — создание
- `PUT /api/templates/{id}` — обновление
