# Скриншоты для инструкции

Добавьте сюда скриншоты интерфейса в формате PNG или JPG. Имена файлов указаны в [ИНСТРУКЦИЯ.md](../ИНСТРУКЦИЯ.md).

Рекомендуемые скриншоты:
- `01-dashboard.png` — главная страница после входа
- `02-campaigns.png` — список кампаний
- `03-doorways.png` — список дорвеев с фильтрами
- `04-offers.png` — офферы и импорт Zeydoo
- `05-settings-integrations.png` — Настройки, блок интеграций
- `06-settings-external.png` — Внешние данные для аналитики
- и другие по мере упоминания в инструкции
